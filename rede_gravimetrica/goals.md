1) read the rede_gravimetrica/tese_embasamento.pdf thesis to understand the problem and the proposed solution.
2) from the rede_gravimetrica/tese_embasamento.pdf, extract the names of the cities that are mentioned in the thesis and create a list of them. Create a .csv file with the list of cities, including the following columns: City Name, Latitude, Longitude. If there's no information about the latitude and longitude of the cities, you search for the coordinates using an online geocoding service and fill in the missing data.
3) create a .csv file with the cities with known absolute gravimetric values, including the following columns: City Name, Latitude, Longitude, Absolute Gravimetric Value. If there's no information about the latitude and longitude of the cities, you search for the coordinates using an online geocoding service and fill in the missing data.
4) create a .csv file with the gravimetric lines, containing the following columns: line name, city from, city to, relative gravimetric value. The city from and city to columns should contain the names of the cities that are connected by the gravimetric line. The gravimetric value column should contain the value of the gravimetric line between the two cities. If there's no information about the gravimetric value, you leave it blank.
