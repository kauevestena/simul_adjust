1) create a clone of "nivelamento" simulator. but instead of using the "nivelamento" data, use the "gravimetria" data (contained and documented in rede_gravimetrica/data folder). The index of the simulator shall be at rede_gravimetrica/index.html
2) the simulator shall be able to read the gravimetry data and display it in a similar way as the nivelamento simulator does. This includes plotting the gravimetry data on a map and allowing users to interact with it (e.g., zooming, panning, etc.).
3) the simulator should also include a feature to display the gravimetry data in a tab (similar to the "Dados" tab in the nivelamento simulator) where users can see the raw data in a tabular format.
4) The mathematical model is meant to be just the same as the one used in the nivelamento simulator, but instead of calculating heights as parameters, it should calculate gravimetric values. The formulas and calculations should be adapted accordingly to reflect the nature of gravimetry data. Nevertheless, the underlying principles of the mathematical model can be retained, ensuring that the simulator provides accurate and meaningful insights into the gravimetry data. Still, check the theory on the web and also in the thesis at rede_gravimetrica/source_info 
5) you can remove the underlying digital terrain model (DTM) from the simulator, as it is not necessary for the gravimetry data (then you can disable the 3D view button).
